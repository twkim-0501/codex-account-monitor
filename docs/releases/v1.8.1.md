**컴퓨터 재시작 후 `이 PC`만 보이던 문제를 수정했습니다.** Codex 앱에서 실행할 때와 Windows 자동 시작 때 서로 다른 설정 폴더를 읽던 것이 원인이었습니다.

이제 `%USERPROFILE%\.codex-account-monitor`의 설정을 함께 사용합니다. 기존에 등록한 계정 설정을 자동으로 가져오고, 계정 연결·최근 조회 결과·중복 알림 방지 기록을 유지합니다. 원본 설정은 삭제하지 않습니다. Primary 표시와 기존 SSH 연결도 유지됩니다.

**[Windows 실행 파일 다운로드](https://github.com/twkim-0501/codex-account-monitor/releases/download/v1.8.1/CodexAccountMonitor.exe)** · [설치와 업데이트 안내](https://github.com/twkim-0501/codex-account-monitor#readme)

기존 앱을 위젯 우클릭 → **종료**로 끝낸 뒤 실행 파일을 교체하고 한 번 실행하세요. 계정을 다시 등록할 필요가 없습니다. Windows 자동 시작도 같은 설정 파일을 쓰도록 갱신합니다. Windows 10/11 x64용이며 .NET은 포함되어 있습니다.

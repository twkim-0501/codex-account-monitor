**현재 데스크톱 앱에 로그인된 계정이 맨 앞에 표시됩니다.** 작은 위젯은 파란 배경과 표시점으로, 상세 창은 파란 카드와 **PRIMARY** 배지로 구분합니다. 밝은 테마와 어두운 테마 모두 지원합니다.

앱에서 로그인 계정을 바꾸면 순서와 강조도 함께 바뀝니다. 같은 계정의 등록된 SSH·로컬 연결을 사용하므로 기존 연결을 변경하거나 중복 계정을 추가하지 않습니다. 등록되지 않은 로그인 계정은 `현재 계정`으로 자동 표시합니다. 나머지 계정은 등록 순서를 유지합니다.

**Codex 앱에서 계정을 바꾼 뒤 사용량이 표시되지 않던 문제를 고쳤습니다.** 로컬 로그인 정보가 바뀌면 다음 조회 때 연결을 새로 만들고, 인증 오류가 나면 한 번 자동으로 다시 연결합니다.

인증 오류가 계속되면 정상 연결처럼 처리하지 않고 로그인 확인 안내를 표시합니다. 계정이 바뀌는 순간의 조회에서도 이전 계정 이름과 새 사용량이 섞이지 않도록 했습니다.

기본 로컬 연결은 현재 이 PC의 Codex 로그인을 따릅니다. 로그아웃한 계정도 계속 보고 싶다면 **별도 로컬 로그인**이나 **해당 계정이 로그인된 SSH 서버**로 연결하세요. 표시 이름만으로 계정이 고정되지는 않습니다.

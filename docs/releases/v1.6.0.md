**언제 초기화권이 지급되고, 언제 한도가 리셋될지 바로 보이도록 카드를 줄였습니다.** 시각을 크게 표시하고 근거는 링크만 남겼습니다. 긴 설명, ‘근거 보기’, 지급 진행 단계는 제거했습니다.

실제 지급이 확인되면 예정 시각 대신 **지급 확인 시각·새 지급량·계정**을 표시합니다. 리셋 완료가 확인되면 그 전에 나온 일회성 예고와 이전 확률은 만료시킵니다. 별도로 예정된 다음 리셋은 유지합니다. 새 시각을 알 수 없으면 **다음 리셋 시각 미정**, 새 확률이 없으면 **—**로 표시합니다.

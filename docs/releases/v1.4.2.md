## 설치하기

1. **[CodexAccountMonitor.exe 다운로드](https://github.com/twkim-0501/codex-account-monitor/releases/download/v1.4.2/CodexAccountMonitor.exe)**
2. 원하는 폴더에 저장하고 더블클릭합니다. Windows 10/11 x64용이며 .NET은 포함되어 있습니다.
3. 처음 사용한다면 **[README의 설치 순서](https://github.com/twkim-0501/codex-account-monitor#1-설치하고-첫-계정-보기)**를 따라 Codex 로그인과 계정 표시를 확인하세요.

이전 버전을 사용 중이면 위젯 우클릭 → **종료** 후 실행 파일을 교체합니다. 기존 계정 연결과 설정은 유지됩니다. 문서를 함께 보관하려면 Assets의 `CodexAccountMonitor-win-x64.zip`을 받습니다.

## 이번 버전의 변화

- 특별 리셋 전망을 **24시간·48시간 원형 확률 게이지**와 짧은 상태로 보여줍니다. **근거 보기**를 열면 요약과 원문 링크가 나옵니다.
- 확률은 CodexReset의 현재 커뮤니티 추정치로 출처를 표시합니다. 오래되거나 조회하지 못한 값은 숫자 대신 ‘—’로 보여줍니다.
- 기존 계정 행에 **초기화권 개수와 만료일**을 통합했습니다. 새 리셋 신호, 실제 한도 변화, 초기화권 만료 임박 알림도 지원합니다.
- README를 **다운로드 → 실행 → 계정 추가 → 화면 읽기** 순서로 정리했습니다. SSH 설정, 개발자 설명, 크레딧은 별도 문서에 유지했습니다.

모니터는 모델 작업을 시작하거나 초기화권을 사용하지 않습니다. 리셋 확률은 실험적 추정이며 실행을 보장하지 않습니다. 실행 파일은 코드 서명되어 있지 않으며 `SHA256SUMS.txt`를 함께 제공합니다.

Windows 10/11 x64 portable build. Download the executable above; no separate .NET installation is required. The interface uses Korean labels. [English setup guide](https://github.com/twkim-0501/codex-account-monitor/blob/main/docs/USAGE.en.md)
